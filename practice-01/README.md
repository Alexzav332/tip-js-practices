## 8. Задание 5

В исходной версии программы были намеренно допущены две ошибки.

### Ошибка 1 — обработка количества задач

Строковые значения:

```js
const completedText = "3";
const additionalText = "2";
```

складывались оператором `+` без преобразования типов.

В результате JavaScript выполнял конкатенацию строк вместо сложения чисел.

**Исправление:**

```js
const completedTotal = Number(completedText) + Number(additionalText);
```

### Ошибка 2 — граница цикла

В исходном варианте использовалось условие:

```js
taskNumber < 4
```

Из-за этого цикл выполнялся только для значений 1, 2 и 3.

Для получения контрольной суммы `1 + 2 + 3 + 4 = 10` условие было исправлено:

```js
taskNumber <= 4
```

### Результат после исправления

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

Для поиска ошибок использовался отладчик браузера. Был установлен breakpoint на вычислении `completedTotal`, после чего были проверены значения переменных и их типы. Также выполнялась пошаговая отладка цикла.
