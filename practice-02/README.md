## 4. Модель данных и функции

В файле src/task-service.js реализованы функции создания задачи, поиска по идентификатору, получения невыполненных задач, получения названий и статистики, добавления, изменения статуса, переименования и удаления задачи.

Функции операций возвращают результат, позволяющий определить успешность выполнения и получить обновлённый массив задач либо сообщение об ошибке. При повторном добавлении существующего идентификатора возвращается ошибка.

**Почему id не равен индексу:** идентификатор остаётся постоянным при изменении порядка элементов и удалении задач. Индекс зависит от положения элемента в массиве.  

**Почему getTaskStats возвращает число, а не строку с процентом:** числовое значение удобно использовать в дальнейших вычислениях и форматировать отдельно при выводе.  

**Какие объекты копируются при изменении задачи:** при поверхностном копировании массива создаётся новый массив, но вложенные объекты автоматически не копируются. Для изменения задачи без изменения исходных данных необходимо создать копию изменяемого объекта и сформировать новый массив.
